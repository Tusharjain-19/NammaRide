## 📖 Overview

**NammaRide** is a high-performance transit navigation application and web platform engineered specifically for the Bengaluru Metro (BMRCL) network. Designed for peak-hour rush conditions, NammaRide solves the real daily challenges faced by over 1,000,000 commuters in India's technology capital:

- **Dead zones in underground stations**: Cellular data often drops inside deep underground tunnels between Kempegowda Majestic, Central College, Vidhana Soudha, and Cubbon Park. NammaRide's proprietary **Offline Geo GPS Engine** runs directly on satellite hardware with zero internet required.
- **Interchange confusion**: Clear, step-by-step platform guidance at Nadaprabhu Kempegowda Station Majestic (Purple ↔ Green) and RV Road (Green ↔ Yellow) prevents boarding the wrong train.
- **Accurate fare & discount calculations**: Instantly compares standard cash token fares against the 5% discount offered by BMRCL Varshik Smart Cards and National Common Mobility Cards (NCMC).
- **Multilingual access**: Native trilingual support across **English**, **ಕನ್ನಡ (Kannada)**, and **हिन्दी (Hindi)**.

## 🛠️ Technology Stack & Architecture

NammaRide is built using a modern, unified codebase bridging a high-speed web application and a native Android application:

```
NammaRide/
├── website/                           # Web Platform (React 18 + Vite + Tailwind CSS)
│   ├── index.html                     # Pre-rendered HTML with Semantic H1-H3 & JSON-LD Schemas
│   ├── package.json                   # Web Dependencies & Scripts
│   ├── vite.config.js                 # Vite Bundler Configuration
│   ├── public/
│   │   ├── sitemap.xml                # Canonical XML Sitemap with Trilingual Hreflangs
│   │   ├── robots.txt                 # AI Crawlers & Search Bot Directives
│   │   ├── llms.txt                   # Curated LLM Context Manifest for AI Search Engines
│   │   ├── llms-full.txt              # Comprehensive Trilingual Fact Sheet & Station Sequences
│   │   └── simulator/                 # Standalone Web App Simulator (100% Offline-capable)
│   └── src/
│       ├── components/                # Modular UI Components (Navbar, Guide, MetaSEO, Themes)
│       ├── context/                   # LanguageContext (EN/KN/HI), ThemeContext (Light/Dark)
│       ├── pages/                     # Stations, Timings, FareCalculator, Blog, Map, Explore
│       └── data/                      # BMRCL Station Coordinates, Timings, & Fares Matrix
├── mobile/                            # Native Android Wrapper (Capacitor 6)
│   ├── capacitor.config.json          # Android Native Bridge Config
│   ├── android/                       # Native Android Studio Project
│   ├── scripts/sync-web.js            # Automated Build-to-Native Web Assets Syncer
│   └── docs/store-assets/             # High-res Play Store promotional screenshots
└── README.md                          # Repository Documentation
```

### Core Technologies
- **Mobile Runtime**: [Capacitor 6](https://capacitorjs.com/) with native `@capacitor/geolocation` satellite receiver.
- **Web Frontend**: [React 18.3](https://react.dev/) + [Vite 5.4](https://vitejs.dev/) with client-side routing.
- **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com/) with curated OLED dark mode (`#000000`) and high-contrast accents.
- **Icons**: [Lucide React](https://lucide.dev/).
- **AI & Search Optimization**: Generative Engine Optimization (GEO), Answer Engine Optimization (AEO), Schema.org `SoftwareApplication`, `FAQPage`, and `TransitSystem` JSON-LD.

## 🚀 Getting Started & Local Development

### Prerequisites
- **Node.js**: v18.0.0 or later
- **npm**: v9.0.0 or later
- **Android Studio** (optional, for compiling native APK/AAB): Hedgehog 2023.1.1+ with Android SDK 34

### 1. Web Development Setup

```bash
# Clone the repository
git clone https://github.com/Tusharjain-19/NammaRide.git
cd NammaRide/website

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### 2. Building Web Production Bundle

```bash
cd website
npm run build
```

The optimized, minified production assets will be generated in `website/dist/`.

### 3. Syncing to Native Android App

```bash
cd ../mobile

# Sync updated web assets into the native Android container
node scripts/sync-web.js
npx cap sync android

# Open Android Studio to run on physical device or emulator
npx cap open android
```

## 🛡️ Security & Privacy Principles

- **Zero Remote Tracking**: User coordinates are never transmitted or saved to external servers.
- **No Binaries or Secrets in Git**: Keystores (`*.keystore`, `*.jks`), binaries (`*.apk`, `*.aab`), and local environment variables (`.env`) are strictly excluded via `.gitignore`.
- **Offline Reliability**: The full metro network graph, transfer matrices, and coordinates are bundled locally within the app.
