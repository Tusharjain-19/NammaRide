## 🚀 Quick Start Commands

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (http://localhost:5173)
npm run dev

# 3. Build optimized production bundle to dist/
npm run build

# 4. Preview production build locally
npm run preview
```
